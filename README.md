# Flingo

A small, fast Android home screen with gesture icons: tap an icon to open the app, swipe up on it to open a
folder (or anything else you choose). Built-in clock with MeteoSwiss weather, notification badges, a search that
also finds contacts, settings and files, and Nova backup import.

This repository only holds the installable APKs. Android 10 or newer.

## Install (with automatic updates)

1. Install **Obtainium** from its [releases page](https://github.com/ImranR98/Obtainium/releases)
   (download the `app-arm64-v8a-release.apk`, open it, allow installing from your browser when asked).
2. In Obtainium: **Add App**, paste `https://github.com/mhandschuh/flingo-release`, tap **Add**, then **Install**.
   Allow Obtainium to install apps when Android asks.
3. Press the **Home** button and choose **Flingo → Always**.

Obtainium checks for new versions and shows a notification; tap it to update. Your layout stays.

## First steps in Flingo

- Long-press empty space → **Settings**. Everything is configured there.
- Coming from Nova? In Nova: Settings → Backup & restore → Backup. In Flingo: Settings → **Import Nova backup**.
- **Notification badges**: Settings → Notification badges, choose Dot or Number, allow notification access.
- **Clock**: long-press empty space → Clock. Long-press the clock → Clock settings to set your postal code for
  the weather and allow the calendar.
- **Search**: swipe up for the app drawer and type. Settings → Search allows contacts and files.
- **Gestures**: long-press an icon → Gestures & icon.
- Save a backup now and then: Settings → **Save Flingo backup**.
